# Smoke checklist

- Iniciar nova carreira
- Abrir pré-jogo e iniciar partida
- Alternar 1x/2x/4x/Instantâneo
- Abrir Transmissão e Outros Resultados
- Gerenciar time e realizar substituição
- Alterar formação durante a partida
- Recarregar durante 1º tempo
- Recarregar no intervalo
- Continuar 2º tempo
- Simular até o fim com confirmação
- Recarregar em FIM DE JOGO
- Processar resultados uma única vez
- Avançar rodada
- Concluir R38
- Salvar carreira no Hall uma única vez
- Abrir resumo do Hall
- Voltar ao menu principal
